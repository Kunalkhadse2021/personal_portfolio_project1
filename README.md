# Personal Portfolio Landing Page

## Project Description

This is a responsive personal portfolio website
developed using HTML5, CSS3 and JavaScript.

It showcases personal information, education,
technical skills, projects and contact details.

## Features

- Personal introduction
- About Me section
- Technical Skills
- Featured Projects
- Contact section
- GitHub and LinkedIn links
- Responsive mobile design
- Mobile navigation menu

## Technologies Used

1. HTML5
2. CSS3
3. JavaScript

## Project Structure

personal_portfolio/
│
├── index.html
├── style.css
├── script.js
└── README.md

## How to Run

1. Download the project.
2. Extract the ZIP file.
3. Open the folder in Visual Studio Code.
4. Open index.html in Google Chrome.
5. View the portfolio website.

## Customization

- Update your personal information.
- Add your email address.
- Add GitHub profile link.
- Add LinkedIn profile link.
- Add your project repository links.
